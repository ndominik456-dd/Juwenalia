# Juwenalia AT Tarnów - Landing Page 🎓🎸

## O projekcie
Jednostronicowa aplikacja webowa (Landing Page) stworzona w celu promocji tegorocznych Juwenaliów Akademii Tarnowskiej. Głównym założeniem projektu jest wzbudzenie silnych, pozytywnych emocji i skuteczne zachęcenie studentów do wzięcia udziału w wydarzeniu poprzez nowoczesny design i interaktywne elementy.

## Zastosowane technologie
*   **HTML5:** Semantyczna struktura strony zapewniająca dostępność (A11y) i dobre SEO.
*   **CSS3:** Zaawansowane stylowanie z użyciem zmiennych CSS (Custom Properties), Flexbox/Grid oraz responsywność (RWD) dopasowana do urządzeń mobilnych (Mobile First).
*   **JavaScript (Vanilla JS ES6+):** Obsługa interakcji, dynamicznych elementów interfejsu (np. odliczanie do startu imprezy, płynne przewijanie).

## Struktura Landing Page'a
Strona została podzielona na następujące sekcje funkcjonalne:
1.  **Hero Section (`#home`):** Główny ekran powitalny z mocnym hasłem reklamowym (Catchphrase), datą wydarzenia, dynamicznym tłem i przyciskiem Call-To-Action (CTA).
2.  **O Wydarzeniu (`#about`):** Emocjonujący opis klimatu tegorocznych Juwenaliów.
3.  **Line-up (`#lineup`):** Prezentacja gwiazd wieczoru i harmonogramu koncertów.
4.  **Galeria / Vibe (`#gallery`):** Przestrzeń na zdjęcia budujące napięcie i oczekiwanie.
5.  **Footer:** Informacje kontaktowe, linki do social mediów uczelni oraz prawa autorskie.
